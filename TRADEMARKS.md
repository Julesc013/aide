# AIDE Trademark And Project Identity Policy

AIDE is open source under Apache-2.0, but that license does not grant trademark
rights. This policy protects the AIDE name, logos, and official project identity
while allowing healthy ecosystem use. It is not legal advice.

## Allowed Without Separate Permission

You may use the AIDE name for truthful, non-confusing references such as:

- "compatible with AIDE"
- "adapter for AIDE"
- "forked from AIDE"
- "uses AIDE protocols"
- "AIDE-inspired"

This use is allowed only when it does not imply official status, sponsorship,
endorsement, or affiliation.

## Requires Permission

You need permission to:

- call a fork or derivative simply "AIDE"
- use AIDE logos as the primary branding for another project
- imply official endorsement
- register confusingly similar domains, package names, social handles, or
  product names
- present a hosted service as the official AIDE service
- use names such as "Official AIDE Cloud", "AIDE Enterprise", or "AIDE Pro" in
  a way that implies upstream approval

## Fork Naming

Forks should be clearly marked as unofficial unless they are maintained by the
upstream AIDE project.

Examples:

```text
Allowed:    AIDE-compatible adapter for JetBrains
Allowed:    Unofficial fork of AIDE
Allowed:    Forked from AIDE
Avoid:      AIDE Pro
Avoid:      Official AIDE Cloud
Avoid:      AIDE Enterprise
```

## Package, Domain, And Service Names

Do not use package names, domains, services, accounts, or project names that are
likely to confuse users into thinking an unofficial project is the upstream AIDE
project or an endorsed AIDE offering.

Truthful namespace references are acceptable when they identify compatibility
without claiming ownership or endorsement.

## No Warranty Or Endorsement

Use of the AIDE name to describe compatibility does not mean the AIDE project
endorses, supports, audits, or guarantees the third-party project.
