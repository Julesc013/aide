# No Forbidden Operations Review

The check did not:

- repair the implementation;
- modify schema, helper, focused tests, build fixtures, or build reports;
- download MCP schemas or SDKs;
- install dependencies;
- start a server;
- launch an MCP subprocess;
- bind a socket or listen on a port;
- send HTTP or start SSE;
- create an MCP session;
- implement authorization;
- resolve credentials;
- serve resources;
- execute tools;
- serve prompts;
- dispatch workers;
- call models, providers, Gateway, GitHub, or network services;
- apply PatchTransactions;
- mutate target repositories;
- implement A2A, Host Contract, Dominium Bridge, Workbench, runtime, or Service;
- create branches or worktrees;
- publish, release, or promote.
