## Scope and remaining limits

The capability is included in the development export, not a newly published release.
Published Lite 1.0.0 assets are unchanged. Lessons remain project-authored data in
the existing outcome ledger. This is a read-only selector, not an automatic writer,
semantic evaluator or model adaptation. Matching hashes establish bytes, not
correctness or permission. Read bounds and snapshot comparisons do not isolate
an arbitrary hostile writer.

No model-performance, total-cost or whole-task-efficiency improvement is claimed.
Actual desktop binding, target-owned DiskEd adoption and the preserved successor
release qualification retain their separate prerequisites. No target repository,
provider, branch protection, public release or machine setting was changed.
