# Remaining Risks

- Local trust enforcement remains local, deterministic, and fixture-backed.
- External identity, credentials, secrets, OIDC/IAM, remote policy engines,
  process launch, worker execution, transaction approval, provider/model calls,
  network calls, preview/apply/rollback, repository mutation, GitHub mutation,
  release, and promotion remain future work.
- Durable local WorkerRun integration is the next proposed build gate.
