# AIDE-BUILD-PROJECT-SEMANTIC-RECORDS-WAVE-01

## Objective

Build report-only semantic record projections for symbols, purpose, contracts,
usage, doc claims, comments, and reuse opportunities.

## Plan

1. Define `SymbolRecord`, `PurposeRecord`, `ContractRecord`, `UsageRecord`,
   and `DocClaimRecord` candidate outputs.
2. Separate observation, claim, validation, and decision states.
3. Preserve doc/comment truth as status-bearing evidence, not automatic fact.
4. Validate and stop at `needs_review`.
