# Accepted Capability Boundary

- accepted_capability: distribution_manifest_v1
- accepted_meaning: stable deterministic portable DistributionManifest v1 identity and metadata for one local AIDE distribution
- does_not_accept: ProjectLock, OwnershipLedger, InstallRecord, MigrationRecord, UpdatePlan, RollbackBundle, UpdateReceipt, install apply, update apply, repair apply, rollback apply, uninstall apply, target repository mutation, public release readiness, release publication, Git tags, GitHub Releases, uploads, signature verification, SBOM generation, network, provider/model calls, worker execution, Workbench/MCP runtime, promotion
