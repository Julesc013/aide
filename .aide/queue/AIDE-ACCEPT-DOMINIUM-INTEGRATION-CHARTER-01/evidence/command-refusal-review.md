# Command And Refusal Review

Accepted future chain:

```text
AIDE WorkUnit or invocation
-> registered Dominium command
-> capability/refusal check
-> deterministic service/process
-> typed result or refusal
-> diagnostic/evidence
-> read-only projection
```

AIDE does not become Dominium command authority. Workbench does not call private tools directly. Refusal remains typed. No command invocation exists yet.
