# Ownership Review

Semantic ownership is accepted as planning law:

- AIDE owns generic governance, coordination, portable protocol envelopes, queue/evidence routing, and accepted AIDE protocol object meanings.
- Dominium owns product and domain meaning, command/result/refusal/diagnostic semantics, and domain contracts.
- Domino owns deterministic execution, replay, apply, undo, and simulation mechanics.
- Workbench owns presentation, context capture, preview interaction, approval interaction, and apply requests only.

Shared concepts have one semantic owner in the charter/check evidence. Workbench and AIDE do not become Dominium command or domain authorities.
