# Transaction Composition Review

Accepted planning layers:

- `PatchTransaction`: current file-oriented proposal, not broadened.
- `DevelopmentTransaction`: future generic governance envelope.
- `DomainMutationBundle`: future domain-owned operation payload.
- `PreviewSession` / `ShadowWorkspace`: future disposable preview boundary.
- Dominium/Domino process: authoritative apply and undo.
- Workbench: preview, approval, and apply request.

This acceptance does not implement any transaction runtime or apply behavior.
