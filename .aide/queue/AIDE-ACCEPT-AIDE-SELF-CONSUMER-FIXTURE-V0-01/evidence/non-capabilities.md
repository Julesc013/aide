# Non-Capabilities

This acceptance does not accept, authorize, or perform:

- real target apply;
- AIDE source repo self-apply;
- source repo apply;
- install/update/migration/rollback/repair/uninstall apply against a real target;
- target repo scan authority;
- canary readiness;
- ScreenSave, Eureka, Dominium, Carbon, or external repository mutation;
- release artifact generation;
- public release readiness;
- release publication;
- GitHub Release source;
- tags, uploads, or GitHub Releases;
- provider/model/network calls;
- push;
- branch/worktree automation;
- runtime, Workbench, Commander, Mobile, Omnigent, MCP live server, A2A live delegation, or automatic update apply.
