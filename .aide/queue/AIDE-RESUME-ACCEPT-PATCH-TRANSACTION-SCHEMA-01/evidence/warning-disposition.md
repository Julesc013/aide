# Warning Disposition

Non-blocking warnings:

- no full JSON Schema implementation;
- no general diff parser;
- no artifact resolver;
- no VCS reachability verification;
- no policy engine;
- no approval engine;
- no apply engine;
- no rollback execution;
- no conformance runner;
- no admission or trust;
- no runtime or adapter execution;
- no accepted case-folding path policy;
- downstream blocked records require explicit resume tasks.

These warnings define the accepted boundary and do not block the no-apply
PatchTransaction protocol acceptance.
