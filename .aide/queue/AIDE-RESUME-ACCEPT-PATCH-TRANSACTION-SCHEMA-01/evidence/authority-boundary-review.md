# Authority Boundary Review

Acceptance preserves these distinctions:

- CapabilityManifest declaration is not admission.
- ConformanceResult presence is not trust.
- EvidencePacket presence is not authorization.
- TestJob reference is not successful test evidence by itself.
- `approval_required` is not approval granted.
- Validated PatchTransaction is not approved or applied PatchTransaction.

No policy, approval, admission, trust, apply, rollback, runtime, or adapter
execution engine exists.
