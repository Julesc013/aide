# Artifact Integrity Review

Accepted artifact-integrity basis:

- deterministic sample artifact digest:
  `sha256:5747bd0d486a73c1b363b0f4c8af974b4ee1f24968a53221eba2c89f187b3c5f`;
- original independent check recomputed the digest successfully;
- repair check confirmed deterministic projection and source immutability.

No artifact resolver, VCS reachability check, branch existence check, merge
claim, or apply authority is accepted.
