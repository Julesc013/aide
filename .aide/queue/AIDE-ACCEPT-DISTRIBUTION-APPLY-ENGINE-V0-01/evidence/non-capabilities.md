# Non-Capabilities

This acceptance explicitly does not accept, authorize, or start:

- real target apply
- source repo apply
- install apply
- update apply against a real target
- migration apply
- rollback apply against a real target
- repair apply
- uninstall apply
- release apply
- public release readiness
- target repo scan authority
- ScreenSave mutation
- Eureka mutation
- Dominium mutation
- external repo mutation
- provider/model/network calls
- branch/worktree automation
- AIDE self-consumer fixture
- project canaries
- release archive creation
- tag creation
- uploads
- GitHub Releases
- source-change PreviewSession
- DevelopmentTransaction apply
- PatchTransaction apply
- Workbench runtime
- Commander or Mobile runtime
- live MCP/A2A/ACP runtime
- general worker runtime
