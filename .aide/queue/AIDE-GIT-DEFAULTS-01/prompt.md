# Owner-directed portable workflow

Make frequent detailed task commits, validated dev integration and reviewed main
promotion the default for AIDE and adopting repos. Main hosting protection is
optional; dev is usually unprotected. Keep task branches local and short-lived,
publishing useful shared, important or blocked checkpoints. Safely remove only
obsolete remote task branches after preservation and ownership checks. Preserve
project overrides and other contributors' work. Use the exact parent admission.
