A local Windows CLI companion for bringing AIDE into a new or existing Git project.

### Highlights

- **Adopt and customize:** safe imports, project-owned rules, preserved direct edits and optional-feature controls.
- **Update and recover:** three-way conflict handling, explicit partial-import recovery, owned-file repair, rollback and removal.
- **Inspect before applying:** dry-run plans bind the exact inputs and effects. Locally generated feedback is shared only when you choose.

### Qualified profile and known limits

- **Profile:** T3 Limited Support, local Windows CLI; qualified on Windows 10 build 19045 with Python 3.14.7. All eight consumer cases and 38 declared public forms have recorded qualification.
- **Compatibility:** this first stable release has no published predecessor. Its update checks use synthetic fixture packs.
- **Scope:** outer editor/shell containment, read isolation, autonomous model operation, hosted GitHub effects and non-Windows lifecycle application have no support claim under this profile. Local use after download does not establish OS-level network isolation.
- **Expected warnings:** fresh-fixture `validate` may report two warnings before optional task/adapter content is generated. Context `verify` may report classified warnings for optional reports, cache and fixture diff scope; inspect them before treating the result as evidence.

**Before changing a project:** preview the plan, retain its exact digest and preserve the original package and project state for recovery. See the included lifecycle and customization references for details.
