# Remaining Risks

## Accepted Warning Class

The reconciler is expected to report stale documentation, OKF, or projection
claims as warnings. Those findings are observations only and do not authorize
repair.

## Deferred

- Independent check: `AIDE-CHECK-DOC-KNOWLEDGE-TRUTH-RECONCILER-01`
- Generated-output ledger: `AIDE-BUILD-GENERATED-OUTPUT-LEDGER-01`
- Any docs/OKF/context repair or regeneration
- Any migration or structure transaction apply
