### Optional Mini worker through the existing execution owner

**Objective.** Exercise the unmodified pinned mini-SWE-agent DefaultAgent through
a small optional AIDE adapter, with actual disposable file changes, independent
acceptance and preserved termination evidence. This advances existing P7.role_fixture
and P7.bindings; it does not replace the task, host, provider or queue owners.

**Design and reuse.** Use the existing managed Python job and WindowsJobHost for
admission, process/resource supervision, collection and retirement. Follow the
existing DiskEd exact-wheel acquisition, bounded offline extraction and isolated
child bootstrap. The selected upstream Model/Environment protocols allow deterministic
fixtures without a provider SDK or network calls during execution. Keep source-only tests under core/execution/tests, outside portable inputs.
Keep upstream wheel bytes unchanged and retain their notices. No fork, substitute DefaultAgent,
fake dependency, generic package manager or competing scheduler.

The initial recipe pins Mini 2.4.6 and the complete imports required by its
DefaultAgent entry path. It is deliberately not an installation of Mini's full
declared CLI/provider/benchmark dependency set. Do not claim pip check, general
Mini CLI or provider compatibility. Inspect the actual acquired modules and
transitive imports before execution; unexplained imports fail rather than stubbing
or quietly acquiring another package. Full provider dependencies are a later recipe.

**Import boundary.** Passive AIDE must not import optional packages. Start the
selected worker in a fresh isolated interpreter with explicit owned dependency
paths, supported MSWEA_GLOBAL_CONFIG_DIR and silent-startup settings established
before import. Keep user config/.env and caches out of the fixture. Verify actual
module/distribution origins and versions. These controls qualify this reviewed
fixture; Windows Job supervision alone does not enforce filesystem/read isolation.

**Acceptance.** Actual upstream completion produces a candidate, never automatic
task acceptance or integration. Independently check the disposable repair and
untouched files. Cover absent/disabled/wrong-version or altered dependencies,
malformed actions, environment failure, step limits, controlled interruption,
partial evidence and cancellation without repeat effects. Missing model usage
remains unknown; deterministic fixture calls are not paid inference or savings.
Preserve task/attempt/source/recipe identity and original outcomes. No optional
dependency may break ordinary Lite use. A replaced recipe needs its own evidence.

**Bounds and stop conditions.** At most four reviewed existing managed allocations:
one acquisition, two execution/lifecycle allocations and one final qualification.
No retry by default. Current 180s/1GiB worker/32MiB scratch/8MiB retained, memory/commit
and disk reserves, root layout and shared locks stay unchanged. If actual archive
or import size does not fit, retain the observation and review a measured amendment.
No broad installation, arbitrary shell, live provider/model request, SDK fallback,
new endpoint, target mutation, auth probe, publication or release-archive rebuild.
A future real model-backed coding attempt and matched comparison remain required
for operational claims and need a fresh finite applicable model grant.
