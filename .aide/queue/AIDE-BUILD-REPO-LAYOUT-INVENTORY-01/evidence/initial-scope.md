# Initial Scope

## Task

`AIDE-BUILD-REPO-LAYOUT-INVENTORY-01`

## Track

Track B: repository structure, root authority, naming, file layout, migration
safety, and organization hygiene.

## Dependency

This task consumes `AIDE-STRUCTURE-01-root-authority-contracts` and the current
root authority contract. It does not accept, supersede, or apply that contract.

## Allowed Work

- Build report-only `.aide` and `core` layout inventory.
- Record naming, authority, generated-output, and report layout findings.
- Record migration risks and validation plan.
- Update queue/index/context/planning/documentation surfaces.

## Forbidden Work

- No moves, deletes, renames, migrations, reference rewrites, aliases, shims,
  root creation, `.aide/reports` restructure, generated OKF edits,
  generated-output source-truth promotion, branch mutation, target mutation,
  provider/model calls, network calls, or Track A implementation.
