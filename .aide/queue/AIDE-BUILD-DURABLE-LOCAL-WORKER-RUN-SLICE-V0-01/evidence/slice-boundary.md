# Slice Boundary

The build records a fixture-backed local WorkerRun into temporary local Service
state. It proves one authorized local reference host run can produce durable
object/event/artifact observations.

It does not accept or implement a general worker harness, autonomous AI worker,
scheduler, leases, persistent background Service, Workbench runtime,
provider/model calls, network calls, preview/apply/rollback, transaction
approval, repository mutation, branch/worktree automation, GitHub mutation,
release, or promotion.
