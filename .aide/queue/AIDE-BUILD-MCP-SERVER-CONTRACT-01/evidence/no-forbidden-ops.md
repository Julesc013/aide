- stdio or Streamable HTTP transport startup;
- endpoint binding, socket opening, SSE, sessions, or HTTP requests;
- MCP authentication, OAuth, token handling, or credential resolution;
- live resources/list, resources/read, prompts/list, prompts/get, tools/list,
  or tools/call;
- resource serving, prompt serving, or tool invocation;
- worker dispatch, model/provider call, Gateway call, or network call;
- PatchTransaction approval/apply, target mutation, branch/worktree automation,
  GitHub mutation, release, promotion, or production readiness;
- A2A, Host Contract, Dominium Bridge, Workbench, Runtime, Service, scheduler,
  leases, or supervisor implementation.
