# Queue Authority Review

The MCP contract preserves:

- `.aide/queue/index.yaml` as canonical queue truth;
- `.aide/protocol/**` as protocol truth;
- `EvidencePacket` as evidence truth;
- OKF as accepted explanatory knowledge projection;
- MCP catalogues and fixtures as generated interoperability projections only.

MCP clients do not become AIDE authority by reading these projections.
