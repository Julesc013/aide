# Validation

Validation is proportionate to this planning-only queue seed.

The validation ladder checks:

- queue and documentation discovery
- duplicate-sensitive search for existing Structure Intelligence and ownership
  work
- whitespace and patch integrity
- task-local evidence completeness
- broad AIDE structural validation
- task status generation
- commit-message policy after commit

No runtime, provider/model, network, target repository, release, branch, or
apply-capable validation is required or authorized for this task.
