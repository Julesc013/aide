# Remaining Risks And Deferrals

- Qualification is limited to disposable fixtures and extracted-artifact
  consumers. Applying AIDE to a live project still requires target-owned
  authority, a target-generated plan, and target-native validation.
- The first update contract uses exact byte ownership. It refuses edited
  managed bytes instead of performing a semantic three-way merge.
- A partial interrupted write is diagnosed and retained for explicit recovery;
  automatic rollback or repair is deliberately not claimed by this slice.
- Receipt-backed repair, rollback, uninstall, migration compatibility, and
  broader stable-profile journeys remain separate implementation work.
- The local release bundle is preview-only. Main promotion, version selection,
  tag creation, upload, and GitHub publication retain their exact review gates.
- The historical main-promotion commit-message disposition and hosted broker
  effect qualification are unchanged and do not become satisfied by these
  product tests.
- No separate model worker or provider was invoked; review evidence here is
  deterministic test, fixture, artifact, and repository validation evidence.
