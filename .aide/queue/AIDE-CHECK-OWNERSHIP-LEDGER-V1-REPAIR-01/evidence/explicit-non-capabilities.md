# Explicit Non-Capabilities

This check does not implement, accept, or authorize:

- implementation repair
- OwnershipLedger acceptance
- InstallRecord, MigrationRecord, UpdatePlan, or RollbackBundle
- install, update, repair, rollback, or uninstall apply
- target repository mutation
- release publication, tags, uploads, or GitHub Releases
- network/provider/model behavior
- Workbench/MCP runtime
- source-change preview/apply/rollback
- promotion
