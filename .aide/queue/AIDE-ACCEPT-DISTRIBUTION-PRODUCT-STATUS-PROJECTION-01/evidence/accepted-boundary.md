# Accepted Boundary

`distribution_product_status_projection_v0` is accepted only as a read-only operator projection.

Acceptance includes:

- generated `current.json`
- generated `current.md`
- read-only `distribution-product status` command surface
- compact operator view over accepted distribution capabilities, accepted boundaries, explicit non-capabilities, warning debt, and readiness states

Acceptance does not include:

- new execution capability
- new distribution apply capability
- real target apply
- AIDE source repo self-apply
- canary readiness
- public release readiness
- archive generation
- package-source readiness
- shadow update apply readiness
- branch/worktree apply readiness
- provider/model/network readiness
- live runtime readiness
- Workbench/Commander/Mobile runtime
- external project mutation
