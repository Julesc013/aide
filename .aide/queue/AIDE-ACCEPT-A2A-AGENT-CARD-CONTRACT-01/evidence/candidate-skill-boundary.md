# Candidate Skill Boundary

Candidate skills remain outside the official AgentCard `skills` array.

The candidate skill catalogue records four future read-only projection candidates. Each remains:

- `implemented: false`
- `callable: false`
- `endpoint_available: false`
- `task_submission_available: false`
- `task_delegation_available: false`

No official AgentCard skill is accepted as callable or implemented.
