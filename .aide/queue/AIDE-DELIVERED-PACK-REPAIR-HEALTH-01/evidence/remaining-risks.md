# Remaining risks and gates

Health inspection is read-only and covers the existing one-file owned-repair
class. It does not apply repair, prove every failure class or change target
ownership. The canary snapshots file paths and bytes, not ACLs, metadata,
empty directories or hostile concurrent-process behavior. OS-level network,
native/hosted and stable-release claims remain separate. Exact `dev` effect
review and remote integration are pending.
