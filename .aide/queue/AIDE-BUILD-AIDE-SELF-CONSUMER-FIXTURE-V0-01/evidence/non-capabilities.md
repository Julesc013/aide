# Non-Capabilities

This build does not implement, authorize, or start:

- real target apply
- source repo apply
- install apply
- update apply against a real target
- migration apply
- rollback apply against a real target
- repair apply
- uninstall apply
- target repo scan authority
- release apply
- public release readiness
- release archive generation
- tags, uploads, or GitHub Releases
- ScreenSave, Eureka, or Dominium canaries
- external repo mutation
- provider/model/network calls
- branch/worktree automation
- independent check
- acceptance
