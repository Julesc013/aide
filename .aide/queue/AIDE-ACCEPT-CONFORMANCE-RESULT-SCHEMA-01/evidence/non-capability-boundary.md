# Non-Capability Boundary

This acceptance does not implement or authorize:

- live conformance case execution;
- conformance runner;
- automatic observation collection;
- profile activation;
- conformance admission;
- automatic admission;
- policy decision;
- subject admission by ConformanceResult;
- trust grant;
- adapter admission;
- adapter execution;
- capability execution;
- runtime capability registry;
- PatchTransaction;
- AdapterManifest;
- ContextPack v2;
- scheduler, leases, or supervisor;
- Test Broker runtime;
- worker execution;
- Runtime, Service, Commander, or Workbench;
- provider, model, Gateway, network, or GitHub mutation;
- branch/worktree automation;
- target apply or active apply;
- release, promotion, production readiness, or release readiness.

The accepted capability is a protocol/evidence projection only.
