# Evidence Requirements Review

The profile declares required evidence fields for future observed results:

- profile subject ref;
- case ID and case ref;
- requirement level;
- evaluator;
- accepted outcomes;
- source refs;
- evidence refs;
- report refs;
- observed status;
- warning disposition.

The current slice only defines these requirements. It does not populate observed
result evidence because `ConformanceResult` is not implemented.
