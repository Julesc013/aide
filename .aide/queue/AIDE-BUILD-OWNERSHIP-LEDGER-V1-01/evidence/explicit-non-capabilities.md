# Explicit Non-Capabilities

OwnershipLedger v1 does not implement:

- install truth
- install plan
- install apply
- update apply
- repair apply
- rollback apply
- uninstall apply
- admission
- authorization
- target repository mutation
- release publication
- Git tags
- GitHub Releases
- uploads
- network calls
- provider/model calls
- Workbench/MCP runtime
- InstallRecord
- UpdatePlan
