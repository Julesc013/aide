Forbidden operations preserved.

- workunit claim
- workunit run
- workunit finish
- workunit repair
- worker leases
- scheduler
- supervisor/runtime
- WorkerRun schema
- TestJob schema
- Test Broker
- Service
- Commander
- provider adapters
- branch/worktree automation
- target repo apply
- active repo apply
- rollback execution
- release/promotion
- push/merge
- network, Gateway, GitHub, and model/provider calls

The implemented surface is queue metadata mutation only.
