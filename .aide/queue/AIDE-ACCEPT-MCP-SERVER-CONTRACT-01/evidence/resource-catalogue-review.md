# Resource Catalogue Review

Accepted resource catalogue facts:

- Resource count: `10`.
- Resource names and URIs are unique.
- Resources map only to accepted AIDE object families.
- Each resource declares MIME type, source kind, authority role, sensitivity, and freshness behavior.
- Each resource remains `not_served_contract_only`.

The accepted capability does not include `resources/list`, `resources/read`, subscriptions, or resource serving runtime behavior.
