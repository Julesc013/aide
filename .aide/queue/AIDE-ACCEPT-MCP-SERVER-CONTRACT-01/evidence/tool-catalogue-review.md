# Tool Catalogue Review

Accepted tool catalogue facts:

- Tool count: `7`.
- Tool names are unique.
- Tool input schemas are object-shaped JSON Schema definitions.
- Every tool is `callable: false`.
- Every tool has `execution_status: not_implemented`.
- Every tool is read-only or report-only.

Tool annotations are not accepted as authorization. No `tools/list` runtime or `tools/call` runtime exists.
