# Lifecycle And Capability Review

Accepted contract shape:

- Lifecycle expectations represent initialization, initialized notification/operation, and shutdown expectation.
- Client and server capability declarations remain distinct.
- Declared feature families are resources, tools, and prompts.
- Implemented live transport count is `0`.
- Callable tool count is `0`.
- Served resource count is `0`.

No lifecycle engine or live MCP connection exists.
