# Proposed additive contract and future archive acceptance

All original38 forms in release-versioning.yaml remain mandatory. Original
consumer families0..7 and their assertions are read-only in this child. Actual
new-archive qualification is not run or claimed here.

| Proposed forms | Existing owner | Required new-archive evidence |
| --- | --- | --- |
| task current; --json; --task-id ID; both | current task view | task selection, recorded completion/obligations, missing/stale/unsafe records, no JSON writes |
| task resume-plan; --json; --task-id ID; both | same current-task projection | interrupted durable task, preserve original attempt and completed effects, unknown admission, next-action references |
| git policy / detect / plan | Git workflow helpers | fresh/brownfield role detection, project defaults/overrides, preserved protections, no mutation from observations |
| review-pack | existing engineering review packet | source references, bounded evidence, correct refusal and no invented verdict |
| quality ledger / reuse / explain-file path / explain-file path --json | quality ledger and explanation | useful existing implementation/test links, missing/stale evidence, heuristic versus semantic claim |
| job effort --work-set path; --json | supplied-work effort | accepted/failed/repaired receipts, duplicate suppression, unknown usage, no whole-cost claim without coverage |

Existing qualified source/development evidence may be reused only for unchanged
subjects and applicable dependencies. A new frozen archive requires actual public
CLI consumers, published1.0.0 upgrade/customization/conflict/recovery checks,
artifact replay, exact release effect review and acquired-byte checks. The proposed
contract adds18 forms, total56. Managed host wake-up, native downstream adoption,
read isolation and model-enabled operation retain their separate open obligations.
