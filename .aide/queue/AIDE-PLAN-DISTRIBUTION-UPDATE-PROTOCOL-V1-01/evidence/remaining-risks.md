# Remaining Risks

- The v1 plan does not yet implement `DistributionManifest`,
  `ProjectLock`, `OwnershipLedger`, `InstallRecord`, `MigrationRecord`,
  `UpdatePlan`, `RollbackBundle`, `UpdateReceipt`, or an apply engine.
- Existing lifecycle helpers remain no-apply.
- Release bundle and GitHub Release draft artifacts remain local preview
  evidence, not public release artifacts.
- First canary targets still require target-local evidence.
- AIDE Lite public install readiness remains unaccepted.
