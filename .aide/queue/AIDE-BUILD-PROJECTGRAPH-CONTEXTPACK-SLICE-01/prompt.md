# AIDE-BUILD-PROJECTGRAPH-CONTEXTPACK-SLICE-01 Prompt

Build a narrow ProjectGraph-driven ContextPack slice.

The slice should help agents choose allowed roots, likely destination paths,
similar files, naming examples, ownership rules, symbols, contracts, tests,
doc claims, warnings, and evidence requirements before creating or editing
files.

Do not replace current ContextPack truth, implement runtime services, mutate
targets, move files, delete files, rewrite references, or call providers/models.
