# Refusal Code Registry

The contract registers stable authorization refusal codes:

- principal_unknown
- principal_inactive
- implementation_not_admitted
- implementation_digest_mismatch
- capability_not_admitted
- policy_denied
- approval_required
- grant_missing
- grant_inactive
- grant_expired
- grant_revoked
- grant_exhausted
- workspace_scope_mismatch
- resource_scope_mismatch
- execution_mode_not_granted
- effect_not_granted
- network_not_granted
- secret_not_granted
- delegation_not_allowed
- delegation_scope_widening
- delegation_expired
- required_feature_unsupported
