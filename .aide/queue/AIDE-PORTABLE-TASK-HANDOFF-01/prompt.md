# Portable continuation through existing task owners

The campaign requires another session to inspect and continue the same WorkUnit
without reconstructing a conversation or repeating uncertain/completed effects.
P3 continuation and P8 bounded offline interchange are dependency-ready separately
from the still-unavailable desktop binding and pending native target ownership.
Deliver a usable finite task-record handoff through the existing task CLI and a
small host-neutral protocol helper. Keep task identity, records, unknown metadata,
status, evidence references and remaining obligations; receiving inspection must
show missing/changed records and preserve readiness as unknown. No new task queue,
execution owner, service, provider route or imported permission.
