Authorized:

- create the wave queue packet

- materialize the next concrete task prompt

- InstallRecord implementation

- tags, uploads, GitHub Releases, or publication
- provider/model/network calls
- Workbench, Commander, Omnigent, worker execution, or runtime work
- branch/worktree automation
