# Remaining Risks

- Preview artifacts may need wording or target-shape changes during independent
  check.
- MCP and A2A preview JSON files are not executable service contracts.
- Future Host Contract and Dominium Bridge work must not treat these previews as
  runtime authority.
- External tool-specific formats may require adjustment before installation in
  target tool locations.

None of these risks blocks a build result because the current slice is
preview-only and explicitly non-authoritative.
