# No Forbidden Operations

Forbidden operations not performed:

- Dominium modification
- sibling repository modification
- branch or worktree mutation
- remote-ref mutation
- GitHub mutation
- downstream queue task materialization
- Host Contract implementation
- Dominium Bridge implementation
- Workbench implementation
- runtime or service startup
- provider/model/network call
- worker execution
- command invocation
- PatchTransaction apply
- target repository mutation
- release or promotion
