# Remaining Risks

Remaining risks are warning-class and deferred:

- `distribution_product_status_v0` is built but not independently checked or accepted.
- The projection includes a generated timestamp and should be regenerated by the command when the status view is refreshed.
- The projection does not verify public GitHub divergence; that field is intentionally `unknown`.
- ScreenSave, Eureka, Dominium, and Carbon canary profiles are not started.
- Local archive canary, public canary readiness, package-source verification, and shadow apply remain future queue tasks.
- Real target apply, source repo self-apply, provider/model/network calls, release publication, branch/worktree automation, runtime, Workbench, Commander, and Mobile remain explicit non-capabilities.
