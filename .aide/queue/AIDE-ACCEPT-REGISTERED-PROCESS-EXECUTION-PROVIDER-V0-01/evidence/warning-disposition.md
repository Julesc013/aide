# Warning Disposition

Warnings accepted:

- cancellation remains explicitly unsupported in v0;
- child-process-tree termination is not implemented;
- persistent idempotency is not implemented;
- resource quotas and streaming artifact storage are not implemented;
- non-Git state providers are not proven;
- Eureka selected command used an implicit public-alpha smoke schema.

These warnings do not block acceptance of the deterministic registered-process
capability substrate.
