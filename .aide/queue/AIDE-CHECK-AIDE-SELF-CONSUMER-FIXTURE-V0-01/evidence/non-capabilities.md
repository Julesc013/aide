# Non-Capabilities

This check does not accept or perform:

- real target apply;
- AIDE source repo self-apply;
- install/update/migration/rollback/repair/uninstall apply against a real target;
- target repo scan authority;
- ScreenSave, Eureka, or Dominium canary work;
- ScreenSave, Eureka, Dominium, or external repository mutation;
- release artifact generation;
- public release readiness;
- tag creation, artifact upload, or GitHub Release publication;
- provider/model/network calls;
- branch/worktree automation;
- push;
- acceptance of `aide_self_consumer_fixture_v0`.
