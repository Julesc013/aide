# Explicit Non-Capabilities

This build does not authorize or implement:

- real target install apply
- real target update apply
- real target migration apply
- real target rollback apply
- real target repair apply
- real target uninstall apply
- source repo self-apply
- target repository mutation
- target repository scan authority
- release archive creation
- tag creation
- upload
- GitHub Release creation
- provider/model/network calls
- self-consumer fixture
- ScreenSave, Eureka, Dominium, or external repository mutation
- real canaries
- Workbench, Commander, Omnigent, live MCP mutation tools, live A2A delegation, source-change PreviewSession, DevelopmentTransaction apply, or PatchTransaction apply
- branch/worktree automation

The only mutation performed by the engine is inside temporary copies of committed fixture workspaces.
