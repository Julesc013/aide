# DistributionManifest Source

ProjectLock v0 binds to the accepted DistributionManifest v1 report under `.aide/reports/distribution-manifest-v1/manifest.json` and the acceptance report under `.aide/reports/distribution-manifest-v1-accept/acceptance-report.json`.

The lock records the selected distribution ref, distribution digest, manifest payload digest, selected components, selected artifacts, and dependency closure.
