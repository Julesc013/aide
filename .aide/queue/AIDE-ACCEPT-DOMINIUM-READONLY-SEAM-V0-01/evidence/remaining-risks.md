# Remaining Risks

- The seam remains offline and read-only.
- Pinned local Dominium remains behind remote `origin/main`.
- Non-Windows platforms were not separately executed.
- Minimum Python 3.11 was not separately executed.
- External Draft 2020-12 validator is unavailable.
- Host/runtime/Workbench functionality is intentionally absent.

These are accepted warning dispositions for `dominium_readonly_seam_v0`; they do
not imply runtime bridge, command invocation, mutation, or WorkUnit validation
slice capability.
