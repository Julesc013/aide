# Downstream Use Boundary

Downstream objects may cite accepted InstallRecord v0 only as install-state metadata and evidence.

They must not infer:

- that install apply is authorized
- that target repository state has been scanned by AIDE
- that source-generated reports are target truth
- that MigrationRecord, UpdatePlan, RollbackBundle, UpdateReceipt, or apply engine behavior exists
- that a public release or canary is ready
