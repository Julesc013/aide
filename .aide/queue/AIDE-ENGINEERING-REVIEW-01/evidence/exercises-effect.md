# Answer-only forward review

At most two fresh independent reviewers receive the actual portable prompt and
one case file each. Allowed effects: read only those files using file inspection,
return a decision with reasons. No tests, edits, outside research, provider calls
or child delegation. Do not provide expected decisions or this evaluator note.
Use the inherited authorized model/effort; do not select another provider.

The supplied histories are clearly fictional inputs. Expected behavior is derived
from their stated contracts: case A must identify the version1 viewer break and
require a bounded compatibility/validation remedy; case B must not require API
deletion, unrelated restructuring or a savings claim to accept the sound change.
Retain both observed decisions and shortcomings, including unexpected outcomes.
These are narrow behavioral exercises, not executable fixture tests, empirical
benchmarks, whole-task cost evidence or proof of general reviewer quality.
