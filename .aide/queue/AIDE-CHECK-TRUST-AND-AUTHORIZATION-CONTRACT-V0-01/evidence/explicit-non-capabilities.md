# Explicit Non-Capabilities

This check does not accept or implement:

- live identity provider
- live policy engine
- live capability grants
- credentials
- secrets
- OIDC/IAM
- runtime enforcement
- worker execution
- transaction approval
- Service/runtime behavior
- provider/model calls
- network calls
- preview/apply/rollback
- repository mutation
- branch/worktree automation
- GitHub mutation
- release or promotion

The checked capability remains a projection-only contract pending acceptance.
