# Non-Capabilities

This acceptance does not accept:

- install truth
- install planning
- install apply
- update apply
- repair apply
- rollback apply
- uninstall apply
- admission
- authorization
- target repository mutation
- release publication
- Git tag creation
- GitHub Release creation
- upload
- network call
- provider/model call
- Workbench runtime
- MCP runtime
- OwnershipLedger v1
- InstallRecord v0
- downstream distribution behavior
