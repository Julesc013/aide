# AIDE Task OS Schemas

This directory contains Task OS v0 JSON Schemas for report-only WorkUnit records, attempts, blockers, repairs, waves, and checkpoints.

X-OS-00 defines contracts only. It does not implement scheduling, repair apply, branch creation, merges, pushes, checkpoint apply, promotion, provider/model calls, network calls, release publication, or target-repo mutation.

The schemas are portable surfaces for later report-only commands in X-OS-01 and capability reality work in X-OS-02.
