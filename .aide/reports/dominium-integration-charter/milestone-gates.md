# Milestone Gates

Success is defined by loops:

1. read-only cross-repo validation loop works;
2. local state survives restart;
3. invocation authorization is enforced;
4. preview leaves authority unchanged;
5. apply is domain/host authoritative;
6. rollback restores preimage;
7. scene edit works end-to-end;
8. legacy host uses the same protocol.

No gate is satisfied merely by this charter. The charter only defines ordering and ownership.
