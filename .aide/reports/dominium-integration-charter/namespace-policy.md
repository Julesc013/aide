# Namespace Policy

- `aide://` object references: AIDE owns identity rules.
- Dominium command IDs: Dominium owns identity and meaning.
- Dominium service IDs: Dominium owns identity and compatibility.
- Dominium document IDs: Dominium owns document semantics.
- Dominium refusal IDs: Dominium owns domain refusal meaning.
- Dominium diagnostic IDs: Dominium owns diagnostic meaning.
- Domino capability/process IDs: Domino owns deterministic execution identity unless Dominium governance assigns a product alias.
- Workbench host/workspace/action/view IDs: Workbench owns host projection identity under Dominium law.
- Bridge mapping IDs: future AIDE-Dominium bridge owns versioned translation IDs.
- Artifact, evidence, and event correlation refs: the producing owner owns native identity; AIDE may aggregate stable refs.

Identity is not a file path. Silent remapping is forbidden. Bridge translations are explicit, versioned, and evidence-backed.
