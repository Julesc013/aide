# Host / Bridge / Provider / Experience Boundary

| Surface | May Own | Must Not Own |
| --- | --- | --- |
| Host Contract | generic context, events, preview, approval, apply-request vocabulary | domain meaning, provider credentials, product truth |
| Host Adapter | mapping a specific IDE/app into Host Contract | generic protocol law, domain semantics, silent mutation |
| Domain Bridge | mapping AIDE objects into Dominium law | Dominium product law, Domino process implementation, host UI behavior |
| Capability Provider | deterministic Dominium/Domino operations | admission by itself, Workbench truth, AIDE queue truth |
| Experience Pack | panels, layouts, commands, workflows | canonical product truth, scheduler authority, private tool bypass |

No surface above is implemented by this charter.

This charter creates no host contract implementation, bridge contract implementation, provider/runtime implementation, or experience implementation.
