# Non-Capabilities

Accepted ProjectLock v0 does not include:

- install truth
- install/update/repair/rollback/uninstall apply
- admission
- authorization
- target repository mutation
- release publication
- Git tags
- GitHub Releases
- uploads
- network calls
- provider/model calls
- Workbench or MCP runtime
- OwnershipLedger v1
- InstallRecord v0
