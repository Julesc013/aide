# Warning Disposition

Accepted non-blocking warnings:

- planning-only charter;
- local Dominium checkout behind remote by 24 commits;
- read-only seam absent;
- Host Contract absent;
- Dominium Bridge absent;
- Workbench integration absent;
- runtime, service, preview/apply/rollback, workers, provider/model calls, and network calls absent.

These warnings are preserved as explicit non-capabilities.
