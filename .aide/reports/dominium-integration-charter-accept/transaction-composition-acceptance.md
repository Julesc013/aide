# Transaction Composition Acceptance

Accepted planning layers:

- `PatchTransaction`: current file-oriented proposal.
- `DevelopmentTransaction`: future generic governance envelope.
- `DomainMutationBundle`: domain-owned operation payload.
- `PreviewSession` / `ShadowWorkspace`: disposable preview boundary.
- Dominium/Domino process: authoritative apply and undo.
- Workbench: preview, approval, and apply request.

PatchTransaction is not broadened by this acceptance.
