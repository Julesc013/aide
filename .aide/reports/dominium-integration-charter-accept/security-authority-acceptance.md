# Security And Authority Acceptance

Accepted security posture:

- MCP authorization is not AIDE authorization.
- A2A discovery is not trust.
- AdapterManifest is not admission.
- ConformanceResult is not permission.
- CapabilityGrant and PolicyDecision remain future, bounded, and per-use.
- Remote workers do not mutate authoritative Workbench state.
- Owning domain or host performs authoritative apply.

No trust object is implemented here.
