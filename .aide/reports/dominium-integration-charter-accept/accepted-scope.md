# Accepted Scope

Accepted as planning law:

- semantic ownership decisions
- source-of-truth hierarchy
- namespace ownership and stable-reference mappings
- object, command/result/refusal, diagnostic, evidence, and event mappings
- transaction composition
- Host/Bridge/Provider/Experience separation
- Workbench non-authority
- compatibility, security, authority, failure, and recovery policies
- first read-only seam and first validation-slice plans
- critical-path DAG, parallel read-only lane, turn-size policy, and milestones

This is not an executable capability.
