# Non-Capabilities

Accepted DistributionApplyEngine v0 does not include:

- real target apply
- source repo apply
- release apply
- public release readiness
- target repo scan authority
- ScreenSave/Eureka/Dominium mutation
- external repo mutation
- provider/model/network calls
- branch/worktree automation
- self-consumer fixture
- project canary
- release publication
- tag creation
- uploads
- GitHub Releases
