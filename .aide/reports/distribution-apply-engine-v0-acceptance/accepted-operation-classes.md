# Accepted Operation Classes

Accepted operation classes:

- `add_managed_file`
- `update_managed_file`
- `remove_managed_file`
- `add_managed_section`
- `update_managed_section`
- `remove_managed_section`
- `preserve_project_owned`
- `preserve_project_overlay`
- `preserve_local_only`
- `preserve_runtime_generated`
- `preserve_evidence_only`
- `preserve_legacy`
- `manual_review_required`
- `refuse`

This acceptance does not widen the operation class allowlist.
