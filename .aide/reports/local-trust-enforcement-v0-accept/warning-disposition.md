# Warning Disposition

Accepted warnings:

- capability remains local, deterministic, and fixture-backed;
- no external identity, credentials, secrets, OIDC/IAM, or remote policy engine;
- no process launch, worker execution, transaction approval, provider/model
  call, network call, preview/apply/rollback, repository mutation, GitHub
  mutation, release, or promotion.

These warnings are truthful non-capability boundaries and do not block
acceptance.
