# Rollout Ring Model

| Ring | Target | Required proof |
| --- | --- | --- |
| 0 | Disposable fixtures | Fresh install, repeated install, upgrade, managed-section preservation, unknown ownership refusal, rollback, uninstall, offline operation. |
| 1 | AIDE self-consumer fixture | AIDE-as-external-consumer install, lock, ownership ledger, upgrade, rollback, uninstall, target state preservation. |
| 2 | ScreenSave | Temporary clone or reviewed branch; AIDE install/update ownership only; ScreenSave-owned proof kernel remains deterministic. |
| 3 | Eureka | Existing AIDE installation upgrade; target-local queue/memory/evidence preservation; guidance regeneration; rollback. |
| 4 | Dominium | Temporary clone or reviewed integration branch; FAST validation, registered-command checks, read-only seam checks, rollback. |
| 5 | Other internal projects | Only after current-state authority, deterministic validation/proof command, thin adapter, and ownership profile exist. |
| 6 | Public canary | Only after earlier rings have accepted evidence. |

The AIDE source repository itself is not an installed target fixture.
