# Public Release Gates

AIDE Lite canary release requires:

- accepted `DistributionManifest v1`
- accepted `ProjectLock v0`
- accepted `OwnershipLedger v1`
- accepted `InstallRecord v0`
- accepted `MigrationRecord v0`
- accepted `UpdatePlan v1`
- accepted `RollbackBundle v0`
- accepted `UpdateReceipt v0`
- fixture-only apply/rollback proof
- AIDE self-consumer fixture proof
- ScreenSave canary proof
- Eureka canary proof
- Dominium canary proof
- Windows/Linux/macOS fixture evidence
- reproducible archives
- checksums and provenance
- license and notices
- security/privacy guide
- offline/no-AI operation proof
- explicit publication authorization

Current Q47/Q48 artifacts are local preview/no-publish evidence and do not
satisfy public release by themselves.
