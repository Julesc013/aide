# Acceptance Report

`registered_process_execution_provider_v0` is accepted with warnings.

The accepted capability is limited to deterministic, pre-registered,
shell-free local process capability execution with immutable specs,
precondition checks, bounded output handling, scrubbing, state probes, decoder
hooks, receipts, outcomes, and fail-closed behavior.

It is not an arbitrary command runner, worker host, Service, Workbench, provider
runtime, preview/apply mechanism, or mutation authority.
