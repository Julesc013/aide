# Explicit Non-Capabilities

RollbackBundle v0 acceptance does not grant:

- rollback apply;
- update apply;
- install apply;
- migration apply;
- uninstall apply;
- target repository mutation;
- target scan authority;
- release readiness;
- release archive creation;
- Git tag creation;
- upload;
- GitHub Release creation;
- provider/model/network calls;
- real project canary authority;
- UpdateReceipt implementation;
- DistributionApplyEngine implementation;
- self-consumer fixture implementation;
- branch/worktree automation.
