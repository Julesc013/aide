# Explicit Non-Capabilities

This acceptance does not accept or implement:

- live ExecutionHost
- LocalProcessExecutionHost
- RemoteExecutionHost
- worker execution
- worker harness
- scheduler
- Service/runtime behavior
- Workbench behavior
- provider/model calls
- network calls
- PreviewSession
- DevelopmentTransaction
- PatchTransaction apply
- repository mutation
- branch/worktree mutation
- GitHub mutation
- release or promotion
