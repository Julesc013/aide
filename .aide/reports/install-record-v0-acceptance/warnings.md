# InstallRecord v0 Acceptance Warnings

- InstallRecord v0 records install-state metadata only.
- InstallRecord v0 does not install, update, migrate, roll back, uninstall, scan, mutate, publish, tag, upload, or call provider/model/network services.
- Source-generated InstallRecord reports are source evidence and not target truth.
- MigrationRecord v0 remains unbuilt.
