# Remaining Risks

Remaining risks are warnings, not blockers for this narrow acceptance:

- no case-folding path policy;
- no full JSON Schema implementation;
- no general diff parser;
- no artifact resolver;
- no VCS reachability check;
- no policy, approval, apply, rollback, runtime, adapter execution, admission,
  or trust engine.

PatchTransaction is accepted only as a no-apply protocol record.
