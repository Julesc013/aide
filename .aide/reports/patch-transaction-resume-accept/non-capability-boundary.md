# Non-Capability Boundary

This acceptance does not authorize:

- patch application;
- active repository apply;
- target-repository mutation;
- approval engine;
- policy engine;
- rollback execution;
- conformance runner;
- live observation collection;
- active ConformanceProfiles;
- admission or trust;
- AdapterManifest;
- admitted worker adapters;
- ContextPack v2;
- Test Broker runtime;
- worker execution;
- scheduler, leases, supervisor, Runtime, or Service;
- Commander or Workbench;
- live MCP or A2A behavior;
- provider, model, Gateway, or network calls;
- GitHub mutation;
- branch or worktree automation;
- release, promotion, or production readiness.
