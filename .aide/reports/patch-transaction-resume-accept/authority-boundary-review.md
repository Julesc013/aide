# Authority Boundary Review

Accepted distinctions:

- CapabilityManifest declaration is not admission.
- ConformanceResult presence is not trust.
- EvidencePacket presence is not authorization.
- TestJob reference is not a successful test result by itself.
- `approval_required` is not approval granted.
- Validated PatchTransaction is not approved PatchTransaction.
- Approved PatchTransaction is not applied PatchTransaction.

No admission, policy, approval, trust, apply, rollback, or runtime engine is
accepted by this task.
