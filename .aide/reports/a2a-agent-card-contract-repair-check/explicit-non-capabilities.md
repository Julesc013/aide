# Explicit Non-Capabilities

AIDE still does not provide:

- live A2A endpoint;
- publishable AgentCard;
- well-known discovery publication;
- agent registration;
- authentication or authorization;
- task submission or delegation;
- streaming or push-notification runtime;
- AgentCard signing;
- worker execution;
- provider/model/network calls;
- PatchTransaction approval or apply;
- target-repository mutation;
- branch/worktree automation;
- GitHub mutation;
- Host Contract;
- Dominium Bridge;
- Workbench;
- Runtime or Service;
- release, promotion, or production readiness.
