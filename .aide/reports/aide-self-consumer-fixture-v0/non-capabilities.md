# Non-Capabilities

The self-consumer fixture does not implement, authorize, or start:

- real target apply
- source repo apply
- install/update/migration/rollback/repair/uninstall apply against a real target
- target repo scan authority
- release apply
- public release readiness
- release archive generation
- tags, uploads, or GitHub Releases
- ScreenSave, Eureka, or Dominium canaries
- external repo mutation
- provider/model/network calls
- branch/worktree automation
- Workbench, Commander, Mobile, MCP, A2A, or ACP runtime
