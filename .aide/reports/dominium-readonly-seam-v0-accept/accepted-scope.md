# Accepted Scope

Accepted:

```text
dominium_readonly_seam_v0
```

This means deterministic offline read-only projection from a pinned local
Dominium checkout into validated seam records.

Not accepted:

- live AIDE-Dominium bridge runtime
- Dominium command invocation
- Workbench integration
- Host SDK runtime
- provider/model/network calls
- worker execution
- PatchTransaction apply
- target mutation
- branch/worktree automation
- release or promotion
