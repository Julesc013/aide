# Explicit Non-Capabilities

Acceptance preserves:

- no Dominium command invocation
- no live Host Contract runtime
- no Host SDK runtime
- no Workbench module
- no bridge runtime
- no service
- no database runtime
- no network transport
- no provider/model calls
- no worker execution
- no PatchTransaction apply
- no DevelopmentTransaction
- no PreviewSession
- no preview/apply/rollback
- no target repository mutation
- no branch/worktree automation
- no GitHub mutation
- no release or promotion
