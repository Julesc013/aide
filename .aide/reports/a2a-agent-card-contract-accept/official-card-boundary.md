# Official Card Boundary

The accepted official AgentCard projection contains only these top-level fields:

- `capabilities`
- `defaultInputModes`
- `defaultOutputModes`
- `description`
- `name`
- `skills`
- `supportedInterfaces`
- `version`

It omits provider, legacy top-level URL, top-level authenticated extended-card fields, unsupported state-transition history fields, AIDE governance metadata, and advertised unimplemented official skills.
