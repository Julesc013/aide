# Accepted Scope

Accepted:

- A2A 1.0 AgentCard contract representation
- A2A specification release `1.0.0` pin
- A2A protocol version `1.0` pin
- standards-clean, non-publishable AgentCard fixture projection
- `supportedInterfaces` fixture projection
- candidate skill governance projection outside official AgentCard fields
- structural validation
- deterministic projection
- inspection and reporting
- conformance expectations
- explicit refusal metadata

Not accepted:

- any live endpoint, runtime, publication, registration, authentication, authorization, delegation, worker execution, provider/model/network call, Host Contract, Dominium Bridge, Workbench, mutation, release, or promotion.
