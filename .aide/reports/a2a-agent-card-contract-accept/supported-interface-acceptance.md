# Supported Interface Acceptance

The accepted fixture exposes one non-live interface:

```json
{
  "url": "https://aide.invalid/a2a/v1",
  "protocolBinding": "JSONRPC",
  "protocolVersion": "1.0"
}
```

The URL uses `.invalid` and is accepted only as a deterministic non-network fixture. No endpoint is bound, started, published, or registered.
