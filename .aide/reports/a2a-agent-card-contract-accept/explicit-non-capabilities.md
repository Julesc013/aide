# Explicit Non-Capabilities

This acceptance does not implement or authorize:

- live A2A endpoint
- `.well-known/agent-card.json` publication
- agent registration
- task submission or delegation
- task status runtime
- streaming or push notifications
- authentication or authorization
- security scheme implementation
- AgentCard signing
- worker execution
- provider/model calls
- network calls
- runtime or service
- Host Contract
- Dominium Bridge
- Workbench
- PatchTransaction approval or apply
- target-repository mutation
- branch/worktree automation
- GitHub mutation
- release, promotion, or production readiness
