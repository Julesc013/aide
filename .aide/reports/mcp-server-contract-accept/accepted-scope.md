# Accepted Scope

Accepted:

- contract representation;
- pinned MCP `2025-11-25` declaration;
- JSON-RPC `2.0` fixture projection;
- resource, tool, prompt, capability, refusal, transport, authorization, and conformance expectation projections;
- structural validation;
- deterministic generation, inspection, and reporting.

Not accepted:

- live server behavior;
- stdio or Streamable HTTP transport implementation;
- endpoint binding;
- authorization implementation;
- resource or prompt serving;
- tool execution;
- workers, providers, models, network calls, runtime, or repository mutation.
