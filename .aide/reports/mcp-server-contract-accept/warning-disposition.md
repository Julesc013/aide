# Warning Disposition

Non-blocking warnings:

- no vendored full official MCP schema validation;
- no live MCP server;
- no stdio or Streamable HTTP transport;
- no endpoint, session, authorization, OAuth, token, or credential behavior;
- no resource serving, prompt serving, tool execution, sampling, elicitation, or MCP tasks;
- no worker execution, provider/model/network call, runtime, or Service;
- future `aide://interop` ReferenceID authority remains advisory.

These warnings are compatible with accepting a contract-only projection.
