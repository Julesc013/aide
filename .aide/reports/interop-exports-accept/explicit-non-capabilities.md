# Explicit Non-Capabilities

AIDE still does not provide:

- live instruction-file installation;
- automatic instruction-file synchronization;
- live MCP server;
- MCP transport;
- MCP authentication;
- MCP tool execution;
- MCP resource serving;
- live A2A endpoint;
- A2A task delegation;
- A2A authentication;
- Host Contract;
- Host SDK;
- Dominium Bridge;
- Dominium Bridge conformance;
- Workbench;
- Commander;
- runtime or Service;
- worker execution;
- provider/model calls;
- network calls;
- credential resolution;
- PatchTransaction approval or apply;
- target-repository mutation;
- branch/worktree automation;
- GitHub mutation;
- release, promotion, or production readiness.
