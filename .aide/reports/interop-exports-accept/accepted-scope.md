# Accepted Scope

Accepted capability:

```text
static_interop_export_previews
```

AIDE can deterministically project inspectable preview artifacts for several
external agent/tool interoperability formats.

The accepted capability covers:

- static preview generation;
- deterministic artifact projection;
- manifest generation;
- content hashing;
- structural validation;
- drift inspection;
- human review;
- reporting.

The accepted capability does not cover live configuration installation, live
MCP, live A2A, live agent integration, host integration, Dominium integration,
Workbench integration, worker execution, provider/model/network calls, runtime
behavior, PatchTransaction application, or repository mutation.
