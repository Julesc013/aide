# Non-Capability Review

ProjectLock v0 remains a proposed lock object only.

It does not implement install truth, install apply, update apply, repair apply,
rollback apply, uninstall apply, admission, authorization, target repository
mutation, release publication, Git tags, GitHub Releases, uploads, network
calls, provider/model calls, Workbench/MCP runtime, preview/apply/rollback, or
OwnershipLedger v1.
