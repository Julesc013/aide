# AIDE Authority Review

The MCP projection preserves AIDE authority boundaries:

- `.aide/queue/index.yaml` remains canonical queue truth.
- Accepted AIDE protocol records remain protocol authority.
- EvidencePacket remains evidence authority.
- OKF remains explanatory projection.
- MCP resources, tools, prompts, and fixtures are generated interoperability
  projections only.

MCP clients are not granted AIDE authority. Tool annotations are not admission
or trust.
