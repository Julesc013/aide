# Explicit Non-Capabilities

AIDE still does not provide:

- live MCP server
- stdio transport
- Streamable HTTP transport
- MCP transport authentication
- MCP tool execution
- MCP resource serving
- MCP prompt serving
- live endpoint binding
- authorization, OAuth, token handling, or credential resolution
- provider, model, Gateway, GitHub, or network calls
- worker execution
- A2A behavior
- Host Contract
- Dominium Bridge
- Workbench
- runtime, Service, scheduler, leases, or supervisor
- PatchTransaction approval or apply
- target repository mutation
- branch or worktree automation
- release, promotion, or production readiness
