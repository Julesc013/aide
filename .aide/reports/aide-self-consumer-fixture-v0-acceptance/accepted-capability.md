# Accepted Capability

Capability label:

`aide_self_consumer_fixture_v0`

Accepted boundary:

- fixture-only;
- temp-workspace-only;
- offline fixture operation;
- AIDE-like installed target model;
- source repo is not installed target;
- target-owned state preservation;
- lifecycle proof scenarios;
- DistributionApplyEngine-backed binding and receipt model.

This accepted capability is not a general installer, updater, rollback engine, public release surface, canary profile, or real target apply authority.
