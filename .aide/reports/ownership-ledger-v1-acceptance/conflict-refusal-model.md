# Conflict And Refusal Model

Accepted refusals include duplicate records, path collisions, case collisions,
file/section conflicts, section overlap, nested ambiguity, source mismatch,
missing evidence, symlink/reparse uncertainty, source-state contamination,
absolute paths, traversal paths, unknown required features, unknown required
extensions, and automatic-apply attempts for `unknown` or `never_touch`.

The model is validation/refusal metadata only.
