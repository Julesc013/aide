# OwnershipLedger v1 Accepted Boundary

Accepted capability: `ownership_ledger_v1`

This accepts OwnershipLedger v1 as target ownership classification and
preservation metadata over accepted DistributionManifest v1 and ProjectLock v0.

Accepted:

- ownership classes;
- file-entry contract;
- managed-section contract;
- Q43 ownership migration projection;
- conflict/refusal model;
- fixture coverage;
- explicit no-apply and no-target-mutation boundary;
- downstream-use constraints.

Not accepted:

- install truth;
- install/update/repair/rollback/uninstall apply;
- migration apply;
- target scan authority;
- target repository mutation;
- project canaries;
- public release readiness.
