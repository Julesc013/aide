# Non-Capability Boundary

Acceptance preserves explicit absence of:

- model calls
- provider calls
- Gateway calls
- network calls
- embedding generation
- agent execution
- worker execution
- command execution
- adapter admission
- adapter trust
- patch application
- target repository mutation
- branch/worktree automation
- runtime, Service, scheduler, leases, supervisor
- Test Broker runtime
- Commander or Workbench
- release, promotion, or production readiness
